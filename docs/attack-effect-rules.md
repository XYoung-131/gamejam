# 攻击技能效果结算

来源为攻击技能表中的玩家描述及此前确认的补充规则。攻击技能资产的 `attackEffectRule` 决定条件结算；未列在下表的技能沿用基础伤害、范围和 Buff 结算。

| 技能 | 本次接入的效果 |
| --- | --- |
| 暴揍 | 对同一目标依次攻击 3 次 |
| 追击 | 攻击 2 次；目标带易伤时再攻击 1 次 |
| 愤怒之拳 | 自身血量严格低于一半时伤害 +2；施放后 25% 概率不扣使用次数 |
| 连续拳 | 本回合每次使用后，后续使用该技能的耐力费用减 1，最多减 3 |
| 落英缤纷 | 本关已使用 0/1/2 次时，本次范围攻击分别结算 1/2/3 轮 |
| 狙杀 | 直接击杀目标时本次不扣使用次数，等同消耗后返还 1 次 |
| 噬咬 | 玩家击杀时回复 1 生命，每关最多实际回复 2；敌人命中即回复 1 |
| 啃咬 | 玩家击杀或敌人命中时，为下回合安排 1 层临时力量，不重复排队 |
| 血盆巨口 | 击杀后获得 1 层力量，最多 2 层 |
| 裁决 | 攻击后目标仍存活且血量不高于 3 时斩杀 |
| 疯狂撕扯 | 相邻基础 4 段；距离 2 格时先靠近 1 格再攻击 2 段；自身每损失 25% 最大生命，追加 1 段 |
| 钢羽、铁翼 | 神圣状态下额外攻击 1 次；钢羽的额外攻击也施加中毒 |
| 后蹬腿 | 攻击后以目标为方向参照，向远离目标方向位移 1 格 |
| 飞身刺击 | 沿直线移动到目标相邻格再攻击；直接击杀后返还本次使用实付耐力的一半，向上取整 |
| 撞击、笨拙冲撞 | 先靠近目标再攻击、击退；笨拙冲撞在自身血量较低或击退失败时给自身施加眩晕 |
| 力竭一击 | 攻击后对自身施加 1 层无力 |
| 光辉打击 | 对选择的地块结算；命中的单位每次移动或传送后再次受到 3 点伤害，最多追踪 2 次，每次施放只扣一次资源 |
| 圣域打击 | 主目标基础伤害 5；身后两格各以基础伤害 2 结算 |
| 雷霆轰击 | 每段从仍存活的敌方单位中随机选取，最多结算 5 段，允许再次选中同一单位 |

技能使用次数、每回合与每关计数存于单位运行时状态。关卡开始和单位初始化时重置关卡计数；回合开始时重置连续拳计数并发放啃咬安排的临时力量。示例场景不参与这些配置。

费用规则：发起抽牌先付 5 点思绪；确认选中的技能时只支付牌面思绪。装入槽位后，每次使用技能只支付牌面耐力，并消耗使用次数，不扣思绪。窃取后灌注也只支付牌面思绪。普通移动与普通攻击仍按自身规则消耗耐力。
