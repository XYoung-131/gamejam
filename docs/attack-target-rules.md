# 攻击技能选目标与范围配置

依据《聚光灯gamejam_攻击技能大全.xlsx》逐张核对。这里记录的是选格与覆盖范围；各技能的击杀奖励、移动、锁定等附加效果仍由各自结算逻辑负责。

| 选目标规则 | 技能 | 覆盖范围 |
| --- | --- | --- |
| 单个单位 | 追击、暴揍、血盆巨口、噬咬、笨拙冲撞、狙杀、连续拳、后蹬腿、力竭一击、推、拳打、抛射、痛殴、啃咬、劈砍、撞击、矢驰、尖刺戳击、愤怒之拳、投掷飞刀、裁决、熔拳、疯狂撕扯、锐啸、钢羽、铁翼 | 资产里的最小/最大射程；疯狂撕扯忽略中途阻挡 |
| 直线上单个单位 | 飞身刺击 | 六个六边形直线方向；相邻目标也有效 |
| 多个单位 | 轰击 | 玩家选择 1～3 个距离 2～3 格的单位；敌人选玩家格和随机两处相邻空地 |
| 选择地块 | 光辉打击 | 地图任意一格，可为空格 |
| 选择地块并爆炸 | 惊喜礼炮 | 距离 3 格内选中心格，覆盖中心和六个相邻格 |
| 自身为中心 | 回旋斩击、自爆 | 所有相邻格 |
| 自身为中心 | 落英缤纷、飞刃之舞 | 距离 2 格内所有格 |
| 全场 | 荧光爆、崩解波动 | 荧光爆覆盖所有单位；崩解波动覆盖敌人与障碍物 |
| 全场随机 | 雷霆轰击 | 全场敌人中随机选取并结算 5 次，可重复命中 |
| 单位后方穿透 | 长距戳刺、圣域打击 | 前者覆盖目标及身后一格；后者覆盖目标及身后两格 |
| 连锁目标 | 思维折跃 | 先选距离 2 格内的目标，再逐次选当前目标周围 2 格内的随机目标，优先单位再障碍物 |
| 相邻地块定向扇形 | 巨尾拍击 | 选相邻格定向，近中远层为 1/3/5 格 |
| 固定地图图案 | 礼炮轰炸 | 四套固定格子图案随机选择一套 |

示例战斗界面：单目标技能点击单位；地块技能点击格子；自身范围、全场、全场随机和固定图案技能选牌后，点击紫色高亮格释放。《轰击》先逐个点击紫色目标，点击已选的深紫色目标即可释放；选满 3 个目标后，再点任意紫色目标也可释放。回车仍可释放已选目标或范围技能，Esc 可取消多目标选择。示例场景文件本身未改动。
