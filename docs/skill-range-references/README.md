# 攻击技能范围图

本目录保存策划确认的五张原始范围图，用于核对 `AttackAreaGeometry.cs` 中的六边形坐标。

| 技能 | 图片 | 游戏规则 |
| --- | --- | --- |
| 巨尾拍击 | `giant-tail-cone.png` | 点击施法者相邻地块确定方向；距施法者 1、2、3 格的三层分别覆盖 1、3、5 格，基础伤害分别为 3、2、1。可朝六个方向旋转。 |
| 礼炮轰炸 | `bombardment-1.png` ~ `bombardment-4.png` | 四套范围固定在地图上，每次等概率随机选择一套。按 `ConceptMap.prefab` 的轴向坐标记录，分别覆盖 30、31、34、26 格；当前地图不存在的格子不会生效。 |

轰击的选格不依赖图片：玩家一次选择 1～3 个射程 2～3 格内的单位；敌方选择玩家所在格，以及该格相邻的随机两个空地。两种情况都只支付一次资源、消耗一次技能使用次数。

项目中的 `Battle.unity` 是示例场景；范围规则由代码和技能资产提供，不需要修改该场景。

可在项目根目录运行 `Tests/AttackAreaGeometryChecks/VerifyRangeImages.ps1`，将四张图上的红色标记与代码中的格子坐标逐一核对。
